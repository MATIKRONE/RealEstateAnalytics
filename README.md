# 🏠 RealEstateAnalytics: Análisis del Mercado Inmobiliario

## 📌 Descripción del Proyecto
Este proyecto de Data Science tiene como objetivo analizar el mercado inmobiliario para identificar oportunidades y zonas óptimas de inversión. A través de un exhaustivo Análisis Exploratorio de Datos (EDA) y modelado estadístico, el proyecto busca transformar datos crudos en *insights* accionables para la toma de decisiones en el sector de bienes raíces.

## 🎯 Objetivos
- Limpiar y estructurar bases de datos inmobiliarias complejas.
- Detectar y tratar valores atípicos (outliers) que distorsionan los precios del mercado.
- Desarrollar modelos y visualizaciones que destaquen las zonas con mejor proyección de inversión.
